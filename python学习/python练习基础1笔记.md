## 一、print 输出与 sep、end

`print()` 的两个常用参数：

| 参数 | 作用 | 默认值 |
| --- | --- | --- |
| `sep` | 多个值之间的分隔符 | 一个空格 |
| `end` | 输出结束后的动作 | 换行 `\n` |

```python
print("晏少平", "郑滨文", "吴志浩", sep='|')
# 结果：晏少平|郑滨文|吴志浩

print("hello", end=" ")
print("world")
# 结果：hello world
```

> **人话理解**：`sep` 是"东西之间的隔板"，`end` 是"说完这句之后干什么"。默认说完就换行，改成 `end=" "` 就变成说完了接着往下说，不换行。

## 二、基本数据类型

```python
num = 1
print(type(num))   # <class 'int'>
```

**布尔型要点**

- `True` 和 `False` 两个 bool 型数据，**开头字母必须大写**。
- 布尔值可以被当成整型来对待：`True` 为 `1`，`False` 为 `0`。

**复数型要点**

- 固定写法为 `a + bj`，虚数单位**只能是 `j`**。

## 三、格式化输出（占位符三种方式）

### 3.1 方式一：`%` 占位符

```python
name = "傻掉郑滨文"        # 字符串类型
print("我去居然是%s" % name)

age = 18
name = "bingbing"
print("我的名字是%s,年龄%d" % (name, age))   # 两个变量用小括号括起来
```

**格式控制符说明**

| 写法 | 含义 | 示例 | 结果 |
| --- | --- | --- | --- |
| `%s` | 字符串 | `"我叫%s" % "bingbing"` | 我叫bingbing |
| `%d` | 整数 | `"%d" % 18` | 18 |
| `%4d` | 整数，占 4 位，不足**前面补空白** | `"%4d" % 123` | `␣123` |
| `%04d` | 整数，占 4 位，不足**前面补 0** | `"%04d" % 123` | `0123` |
| `%f` | 浮点数，默认小数点后 **6 位** | `"%f" % 3.14` | 3.140000 |

> `%4d` 里的 `4` 代表设置位数，不足就在前面补空白；`%04d` 前面的 `0` 表示用 0 补在前面。

### 3.2 方式二：`format()`

```python
print("我的名字是{}，年龄{}".format("bingbing", 18))
```

### 3.3 方式三：f-string（最推荐）

```python
name = 'bingbing'
age = 20
print(f"我的名字是{name},我今年{age}岁了")
```

> `f` 写在引号前面，字符串里用 `{}` 直接塞变量名，可读性最好，日常首选这种。

## 四、运算符

**算术运算符**：`+` `-` `*` `/` `//` `%` `**`

- 参与运算时**只要有一个是浮点数，结果也会是浮点数**。
- 优先级：**幂 `**`（最高） > 乘、除、取余、取整除 `* / % //` > 加、减 `+ -`**

**赋值运算符**：`=` `+=` `-=` `*=` `/=` ...

> **易错点**：赋值运算符必须**连着写**，中间不能有空格，写成 `- =` 会报错。

## 七、循环结构

### 7.1 while 循环

```python
# 定义初始变量
while 条件:
    # 循环要做的事情
    # 改变变量
```

### 7.2 for 循环

```python
for 临时变量 in 可迭代对象:
    循环体
```

> **注意冒号和缩进。**
> **可迭代对象**就是"能一个个取出来遍历的整体"。现阶段只需记住：**字符串是可迭代对象，整型不是**。

```python
st = 'hellopython'
for i in st:      # i 是临时变量，可以随便写，i 是常规写法
    print(i)
```

### 7.3 range() 函数

用来记录循环次数，相当于一个计数器。

```
range(start, end, step)   # 遵循"包前不包后"原则，即 [start, end)
```

- 只写一个数：这个数字就是**循环次数**，默认从 0 开始。
- 写两个数：前面是开始位置，后面是结束位置。

```python
for i in range(3):        # 0 1 2
for i in range(1, 4):     # 1 2 3
for i in range(1, 10, 2): # 1 3 5 7 9
```

### 7.4 break 与 continue

> `break` 和 `continue` **只能放在循环内**。

## 八、字符串

### 8.1 字符串编码

常用编码：**ASCII、GB2312、Unicode、GBK、UTF-8**。

本质上就是**二进制数据与语言文字的一一对应关系**。

| 编码 | 特点 | 优点 | 缺点 |
| --- | --- | --- | --- |
| Unicode | 所有字符都是两个字节 | 字符与数字之间转换速度快 | 占用空间大；纯英文文本有一半空间浪费 |
| UTF-8 | 变长，对不同字符用不同长度表示 | 节省空间 | 转换速度较慢，每次都要计算用几个字节 |

### 8.2 编码与解码

| 方法 | 作用 |
| --- | --- |
| `encode()` | 将字符串转换成字节（bytes） |
| `decode()` | 将字节转换回字符串 |

```python
a = 'hello'
print(a, type(a))          # hello <class 'str'>

a1 = a.encode()
print('编码后：', a1)       # b'hello'
print(type(a1))            # <class 'bytes'>

a2 = a1.decode()           # 解码
print(a2, type(a2))        # hello <class 'str'>
```

> **bytes 是什么**：可以理解成一个数据类型，先只要知道它和字符串类型之间怎么互相转换就够了。带 `b` 前缀（`b'hello'`）就说明它是一串字节，不是给人看的文字。

```python
st = "这里是六星教育"
st1 = st.encode("utf-8")
print(st1, type(st1))
st2 = st1.decode("utf-8")
print(st2, type(st2))
```

> **关键点**：用什么编码（`encode`）就用什么解码（`decode`），对不上就会乱码。

### 8.3 字符串常见操作

#### ① 拼接与重复

```python
name1 = "六星"
name2 = "教育"
print(name1 + name2)                    # 六星教育

print("好好学习，天天向上" * 5, sep='\n')
print("好好学习，天天向上\n" * 5)
```

> `*n` 就是重复输出 n 次，要输出多少次 `*` 后面就写多少。

#### ② 成员运算符

| 运算符 | 含义 |
| --- | --- |
| `in` | 包含返回 `True`，不包含返回 `False` |
| `not in` | 不包含返回 `True`，包含返回 `False` |

```python
name = 'bingbing'
print('b' in name)    # True
print('a' in name)    # False
```

作用：检查字符串中是否包含了某个字符或多个字符。

#### ③ 切片

对操作的对象截取其中一部分。语法：

```
[开始位置 : 结束位置 : 步长]
```

**包前不包后**：从起始位置开始，到结束位置的前一位结束，不包含结束位置本身。

```python
st = 'abcdefghi'
print(st[0:4])     # abcd
print(st[4:7])     # efg
print(st[3:])      # defghi
print(st[:7])      # abcdefg
print(st[-1:])     # i
print(st[:-1])     # abcdefgh
print(st[-1:-5])   # 空输出（方向反了，切不到东西）
```

**步长规则**

- 不写步长默认是 `1`。
- 步长的**绝对值大小**决定切取的间隔，**正负号**决定切取方向。

#### ④ 查找与统计

| 方法 | 返回 | 找不到时 |
| --- | --- | --- |
| `find(子串, 开始, 结束)` | 子串开始位置的下标 | 返回 `-1` |
| `index(子串, 开始, 结束)` | 子串开始位置的下标 | **报错** |
| `count(子串, 开始, 结束)` | 出现的总次数 | 返回 `0` |

开始和结束位置下标可以省略，表示在整个字符串中查找；同样遵循包前不包后。

```python
name = 'bingbing'
print(name.find('ing'))     # 1
print(name.find('bing'))    # 0
print(name.find('b', 3))    # 4
print(name.find('b', 5))    # -1，超出范围返回 -1
print(name.find('b', 5, 4)) # -1
```

> `find` 和 `index` 的唯一区别：**没找到时 find 返回 -1，index 直接报错**。

#### ⑤ 判断首尾

```python
startswith(子串, 开始, 结束)   # 是否以某子串开头，返回 True/False
endswith(子串, 开始, 结束)     # 是否以某子串结尾，返回 True/False
```

设置了开始和结束位置下标时，只在指定范围内检查。

#### ⑥ 大小写判断与转换

```python
st = 'sixstar'
print(st.isupper())      # False，检测是否全部为大写
```

| 方法 | 作用 |
| --- | --- |
| `isupper()` | 所有字符是否都为大写 |
| `capitalize()` | 第一个字符大写，其他都小写 |
| `lower()` | 全部大写字母转为小写 |
| `upper()` | 全部小写字母转为大写 |

```python
st = 'bingbing'
print(st.capitalize())   # Bingbing
```

#### ⑦ 替换与切分

```python
replace(旧内容, 新内容, 替换次数)
split(分隔符, 分割次数)
```

```python
name = '好好学习，天天向上'
print(name.replace('天', '时'))      # 好好学习，时时向上
print(name.replace('天', '时', 1))   # 好好学习，时天向上

st = 'hello,python'
print(st.split(','))       # ['hello', 'python']
print(st.split('a'))       # ['hello,python']  不包含分隔内容就不分割，作为整体
print(st.split('o', 2))    # ['hell', ',pyth', 'n']  只分割两次
```

## 九、列表 list

### 9.1 基本格式

```python
列表名 = [元素1, 元素2, 元素3]
```

- 所有元素放在 `[]` 内，元素之间用 `,` 隔开。
- 元素之间的数据类型可以各不相同。
- 列表是**可迭代对象**，可以用 for 循环遍历取值。

### 9.2 添加元素

| 方法 | 行为 | 示例结果 |
| --- | --- | --- |
| `append(x)` | **整体**添加一个元素到末尾 | `['one','two','three','four']` |
| `extend(x)` | **分散**添加，把另一个可迭代对象里的元素逐一加进去 | `['one','two','three','f','o','u','r']` |
| `insert(idx, x)` | 在指定位置插入 | 原元素后移 |

```python
li = ['one', 'two', 'three']
li.append('four')
li.extend('four')
li.insert(3, 'four')
```

> **关键区别**：`append` 像整袋放进去，`extend` 像拆开一粒粒放进去。`extend` 所加的内容**一定要是可迭代对象**。
> `insert` 指定位置如果有元素，原有元素就会后移；下标越界会报错。

### 9.3 修改元素

直接通过下标修改：

```python
li = [1, 2, 3]
li[0] = 'a'
print(li)    # ['a', 2, 3]
```

### 9.4 查找元素

| 方式 | 作用 |
| --- | --- |
| `in` | 存在返回 `True`，不存在返回 `False` |
| `not in` | 存在返回 `False`，不存在返回 `True` |
| `index()` | 同字符串用法，返回下标 |
| `count()` | 同字符串用法，返回出现次数 |

### 9.5 删除元素

| 方法 | 作用 | 注意 |
| --- | --- | --- |
| `del li[下标]` | 根据下标删除 | `del li` 则删除整个列表 |
| `pop(下标)` | 删除指定下标的数据 | Python 3 默认删最后一个；只能按下标，不能按元素；下标不能越界 |
| `remove(元素)` | 根据指定元素删除 | 默认只删**第一个**匹配项，不会全删 |

```python
li = ['a', 'b', 'c', 'd']
del li[2]
li.pop()
li.remove('d')
```

### 9.6 排序

```python
li.sort()      # 按特定顺序重新排列，默认从小到大
li.reverse()   # 倒序，把列表倒置
```

### 9.7 列表推导式

**格式一**：`[表达式 for 变量 in 列表]`

```python
# 等价于
for i in range():
    循环表达式
```

**格式二**：`[表达式 for 变量 in 列表 if 条件]`

```python
# 等价于
for i in range(1, 11):
    if 条件表达式:
        循环表达式
```

> `in` 后面不仅可以放列表，还可以放 `range()` 或其他可迭代对象。

### 9.8 列表嵌套

含义：一个列表里面又有一个列表，例如 `[[1, 2], [3, 4]]`。

## 十、元组 tuple

### 10.1 基本格式

```python
元组名 = (元素1, 元素2, 元素3)
```

- 所有元素包含在小括号内，元素之间用逗号隔开，不同元素也可以是不同的数据类型。

> **坑点**：只有一个元素时，要在元素后面**加一个逗号**，否则会被当成这个唯一值本身的类型。

```python
tub = (1,)    # 正确，这是元组
tub = (1)     # 错误，这是 int
```

### 10.2 与列表的区别

**元组只支持查询操作，不支持增删改操作。**

`count()`、`index()`、`len()` 跟列表使用方法相同。

### 10.3 应用场景

1. 函数的参数和返回值
2. 格式化输出后面的 `()` 本质上就是一个元组
3. 数据不可以被修改，保护数据的安全

## 十一、字典 dict

### 11.1 基本格式

```python
字典名 = {键1: 值1, 键2: 值2, ...}

dic = {'name': 'sixStar', 'age': 18}
```

> **注意**：键值对形式保存，**键具有唯一性**，但值可以重复。如果键重复了不会报错，前面的值会被后面的值覆盖。

### 11.2 查看元素

> **字典中没有下标**，不能根据下标查询，查找元素要根据键名，**键名相当于下标**。

| 方式 | 写法 | 键不存在时 |
| --- | --- | --- |
| 按名取值 | `变量名[键名]` | **报错** |
| get 方法 | `变量名.get(键名)` | 返回 `None`，可另设默认值 |

```python
dic = {'name': 'sixStar', 'age': 18}
print(dic['age'])                  # 18
print(dic.get("tel", '不存在'))     # 不存在
```

### 11.3 修改与添加元素

```python
变量名[键名] = 值
```

> **规则**：键名**存在就是修改**，**不存在就是新增**。

```python
dic['age'] = 20        # 修改
dic['tel'] = '110'     # 新增
```

### 11.4 删除元素

| 写法 | 作用 | 注意 |
| --- | --- | --- |
| `del 字典` | 删除整个字典 | — |
| `del 字典名[键名]` | 删除指定的键值对 | 键名不存在就报错 |
| `dic.clear()` | 清空字典里的内容，但保留字典本身 | — |
| `dic.pop(键名)` | 删除指定键值对 | 键不存在会报错 |
| `dic.popitem()` | 删除一个键值对 | 3.7 之前随机删，3.7 之后默认删最后一个 |

### 11.5 长度与遍历

| 方法 | 返回 |
| --- | --- |
| `len(dic)` | 长度，一个键值对算 1 |
| `dic.keys()` | 所有键名，如 `dict_keys(['name', 'age'])` |
| `dic.values()` | 所有值，可用 for 循环取出 |
| `dic.items()` | 所有键值对，以元组形式，如 `dict_items([('name', 'sixStar'), ('age', 18)])` |

```python
for i in dic:      # 直接遍历字典，只取出键名
    print(i)
```

### 11.6 应用场景

使用键值对，存储描述一个物体的相关信息。

## 十二、集合 set

### 12.1 基本格式

```python
s1 = {1, 2, 3}
```

**三条注意**

1. 集合是**无序**的，里面的元素是**唯一**的。
2. 可以用于给列表或元组**去重**。
3. 集合中的数据也可以是不同类型。

```python
s1 = {}      # 这是定义空字典，不是空集合！
s1 = set()   # 这才是定义空集合
```

> 由于无序性，**不能修改集合中的值**。

### 12.2 添加元素

| 方法 | 行为 |
| --- | --- |
| `s.add(x)` | 一次只能添加**一个**元素 |
| `s.update(x)` | 把传入的元素**拆分**，一个一个放进集合 |

```python
s2 = {1, 2, 3, 4}
s2.update('567')
print(s2)      # {1, 2, 3, 4, '7', '6', '5'}
```

> `update` 的元素必须是能被 for 循环取值的**可迭代对象**。

### 12.3 删除元素

| 方法 | 行为 |
| --- | --- |
| `remove(x)` | 有就删除，**没有会报错** |
| `pop()` | 全是整型时默认删第一个；不全是整型时删哈希表排序后的第一个 |
| `discard(x)` | 有就删除，**没有则什么都不发生**，不报错 |

### 12.4 交集与并集

```python
交集 &    # 共有的部分；没有共有的部分则返回空集合 set()
并集 |    # 所有的都放一起，重复的不算
```

## 十三、类型转换

| 函数 | 作用 | 注意 |
| --- | --- | --- |
| `int()` | 转整数 | 只能转换由数字组成的字符串；浮点转整型会**去掉小数点及后面数值**；除数字和正负号外的字符会报错，正负号只能写在前面 |
| `float()` | 转小数 | 字符串中出现正负号、数字、小数点以外的字符则不支持转换 |
| `str()` | 转字符串 | **任何类型**都可以转字符串 |
| `eval()` | 执行一个字符串表达式，返回表达式的值 | 可实现 list、dict、tuple、str 之间的转换 |
| `list()` | 将可迭代对象转成列表 | 支持 str、tuple、dict、set；**字典转列表会取键名**作为列表的值 |

```python
# str -> list
str1 = "[[1,2],[3,4],[5,6]]"
print(type(str1))       # <class 'str'>

li = eval(str1)
print(li, type(li))     # [[1, 2], [3, 4], [5, 6]] <class 'list'>
```

> **安全提醒**：`eval()` 非常强大，但**不够安全**，容易被恶意构造的数据利用，实际项目中不建议使用。

## 十四、深浅拷贝

### 14.1 赋值

等于**完全共享资源**，一个值的改变会完全被另一个值共享，会随着原对象一起变化。

### 14.2 浅拷贝（数据半共享）

```python
import copy

li = [1, 2, 3, [4, 5, 6]]
li2 = copy.copy(li)
```

- 会创建**新的对象**，只拷贝第一层的数据，**嵌套层仍指向原来的内存地址**。
- 外层的内存地址不同，但内层的内存地址相同。

```python
print("li内存地址：", id(li))
print("li2内存地址：", id(li2))    # 不一样，说明不是同一个对象

li.append(8)
print('li', li)     # [1, 2, 3, [4, 5, 6], 8]
print('li2', li2)   # [1, 2, 3, [4, 5, 6]]   外层不受影响

li[3].append(7)
print('li', li)     # [1, 2, 3, [4, 5, 6, 7], 8]
print('li2', li2)   # [1, 2, 3, [4, 5, 6, 7]]  嵌套层被一起改了
```

- **优点**：拷贝速度快，占用空间少，拷贝效率高。

> **人话理解**：浅拷贝像"复印了一份通讯录封面，但里面夹着的还是同一张便利贴"。改封面各改各的，改便利贴两边一起变。

### 14.3 深拷贝（数据完全不共享）

- 外层的对象和内部的元素**都拷贝了一遍**。
- 深拷贝数据变化只影响自己本身，跟原来的对象**没有关联**。

```python
li3 = copy.deepcopy(li)
```

## 十五、可变类型与不可变类型

### 15.1 可变类型

**含义**：变量对应的值可以修改，但是**内存地址不会发生改变**。

常见可变类型：**list、dict、set**

```python
li = [1, 2, 3, 4]
print("li的原内存地址：", id(li))   # 1848772383872
li.append(5)
print(li)                          # [1, 2, 3, 4, 5]
print("li的现内存地址：", id(li))   # 1848772383872（同一个地址）
```

### 15.2 不可变类型

**含义**：变量对应的值不能被修改，如果修改就会生成一个新的值，从而分配新的内存空间。

常见不可变类型：**int、str、tuple**

> **注意**：前面所说的深浅拷贝**只针对可变对象**，不可变对象没有拷贝的说法。
