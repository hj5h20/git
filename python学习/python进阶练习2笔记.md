## 一、`__init__()` 与 `__new__()`

### 1.1 `__init__()`：初始化对象

```python
class Test(object):
    def __init__(self):
        print("这是__init__()")

te = Test()
```

### 1.2 `__new__()`：创建对象

**来源**：`object` 基类提供的内置的**静态方法**。

**两个作用**

1. 在内存中为对象**分配空间**。
2. **返回对象的引用**。

```python
class Test(object):
    def __init__(self):
        print("这是__init__()")

    def __new__(cls, *args, **kwargs):      # cls 代表类本身，这里是静态方法
        print("我是__new__()")
        print(cls)

        # 对父类方法进行扩展，也叫方法的重写
        # 三种写法中这里选 super().方法名()
        res = super().__new__(cls)          # res 里面保存的是实例对象的引用

        # __new__() 是静态方法，形参里面有 cls，实参就必须传 cls
        return res

te = Test()
print("te", te)
```

> **致命注意点**：重写 `__new__()` **一定要 `return super().__new__(cls)`**。否则 Python 解释器得不到分配空间的对象引用，就**不会调用 `__init__`**，对象也建不出来。

### 1.3 对象实例化的完整步骤

```
① 执行 __new__()
   （如果没写 __new__，默认调用 object 里的 __new__）
   ↓ 返回一个实例对象
② 再去调用 __init__()，对对象进行初始化
```

```python
class Person(object):
    def __new__(cls, *args, **kwargs):
        print("这是new方法")
        print("返回值", super().__new__(cls))
        return super().__new__(cls)

    def __init__(self, name):
        self.name = name
        print("名字是：", self.name)

pe = Person('bingbing')
print(pe)
```

> **执行顺序验证**：输出里"这是new方法"一定在"名字是：bingbing"之前 —— 先造出来，才能装修。

### 1.4 两者对比总结

| 对比项 | `__new__()` | `__init__()` |
| --- | --- | --- |
| 职责 | **创建**对象 | **初始化**对象 |
| 返回值 | 返回对象引用 | 不返回任何值（只能 `None`） |
| 级别 | **类级别**的方法 | **实例级别**的方法 |
| 作用 | 分配内存空间 | 定义实例属性 |

> **一句话记法**：`__new__` 是"盖房子"，`__init__` 是"装修房子"。没有房子无从装修。

## 二、单例模式

### 2.1 含义与优劣

**定义**：可以理解成一个特殊的类，这个类**只存在一个对象**。

| 项目 | 说明 |
| --- | --- |
| 优点 | 可以节省内存空间，减少不必要的资源浪费 |
| 缺点 | 多线程访问时容易引发**线程安全问题** |

> **判断依据**：以往知识点告诉我们，一个类每次创建对象时内存地址都会改变；而单例模式所创建的类，实例化时对象的内存地址**不会改变**，是同一个对象。

### 2.2 四种实现方式

1. 通过 `@classmethod`
2. 通过装饰器实现
3. **通过重写 `__new__()` 实现（重点）**
4. 通过导入模块去实现

### 2.3 重写 `__new__()` 实现单例（重点）

**设计流程（四步）**

1. 定义一个**类属性**，初始值为 `None`，用来记录单例对象的引用。
2. **重写** `__new__()` 方法。
3. 进行判断：如果类属性是 `None`，把 `__new__()` 返回的对象引用保存进去。
4. 返回类属性中记录的对象引用。

```python
class Singleton(object):
    obj = None                          # 第 1 步：记录单例对象的引用

    def __new__(cls, *args, **kwargs):  # 第 2 步：重写 __new__
        print("这是__new__()方法")

        if cls.obj == None:             # 第 3 步：判断类属性是否为空
            cls.obj = super().__new__(cls)

        return cls.obj                  # 第 4 步：返回记录的对象引用

    def __init__(self):
        print("我是__init__()")

s = Singleton()
print("s", s)

s2 = Singleton()
print("s2", s2)
```

> **结果**：`s` 和 `s2` 的内存地址完全一样 —— 每一次实例化所创建的对象都是同一个。

> **人话理解**：像公司只有一台公用打印机。谁要打印都拿到"那一台"，`obj` 这个类属性就是"记着那台打印机放在哪"的便签。第一次去发现还没有，就买一台记下来；以后每次都按便签上的位置去拿同一台。

### 2.4 通过导入模块实现单例

**做法**：在另外一个 `.py` 文件里写一个类，在本文件里导入并实例化对象时**起不同的别名**，但它们是同一个对象，这些别名的内存地址都一样。

> **结论**：**模块就是天然的单例模式**。因为模块在 Python 里只会被导入（执行）一次，后续的 import 拿到的都是同一份缓存。

## 三、魔法方法与魔法属性

### 3.1 含义

在 Python 中，`__xx__()` 形式的函数叫做**魔法方法**，指的是具有特殊功能的函数。

> **区分技巧**：**有小括号的是方法，没有小括号的是属性。**

### 3.2 `__doc__`：类、函数的描述信息

```python
class Person(object):
    """人类--类的描述信息"""      # 只能使用多行注释，单行注释无效
    pass

print(Person.__doc__)            # 人类--类的描述信息


def sing():
    """111"""
    pass

print(sing.__doc__)              # 111
```

> **要点**：`__doc__` 取的是**文档字符串**，也就是写在类或函数体第一行的三引号字符串。用 `#` 写的单行注释取不到。

### 3.3 已学魔法方法速查

| 魔法方法 | 触发时机 | 作用 |
| --- | --- | --- |
| `__init__()` | 实例化对象时自动调用 | 初始化对象、定义实例属性 |
| `__new__()` | 实例化的第一步 | 分配内存空间、返回对象引用 |
| `__del__()` | 对象被删除或程序结束时 | 释放资源、收尾处理 |
| `__doc__` | 访问时 | 返回类/函数的文档字符串（属性，无括号） |
