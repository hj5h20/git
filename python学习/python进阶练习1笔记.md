## 一、面向对象与面向过程的区别

| 思想 | 生活类比 | 侧重点 |
| --- | --- | --- |
| 面向过程 | **手洗衣服** | 着重**过程**：分析出一个个步骤，把步骤用一个个函数实现，再依次调用（每一步都得亲自来） |
| 面向对象 | **机洗衣服** | 着重**谁去帮我做这件事**（偷懒，找别人帮我做） |

> **一句话**：面向过程是"我自己一步步干"，面向对象是"我找个对象替我干"。

## 二、类与对象

### 2.1 基本概念

- **类**：一系列具有**相同属性和行为**的事物的统称，不是真实存在的事物。
- **对象**：类的具体实现，是类创建出来的真实存在的事物，是面向对象思想的核心。

> **开发顺序**：**先有类，再有对象**。类是图纸，对象是按图纸造出来的实物。

### 2.2 类的三要素

| 要素 | 含义 |
| --- | --- |
| 类名 | 类的名字 |
| 属性 | 对象的特征描述，用来说明**是什么样子的** |
| 方法 | 对象具有的功能（行为），用来说明**能够做什么** |

**举例：人类**

- 类名：`人类`
- 属性：身高、体重、年龄
- 方法：走路、说话、学习

### 2.3 定义类

```python
class 类名:          # 类名必须符合标识符规定，遵循大驼峰命名法，见名知义
    代码块
```

```python
class Washer:
    height = 800     # 类属性：就是类所拥有的属性

print(Washer.height)     # 查看类属性：类名.属性名

Washer.width = 450       # 新增类属性：类名.属性名 = 值
print(Washer.width)
```

### 2.4 创建对象

创建对象的过程也叫**实例化对象**。

```python
对象名 = 类名()

wa = Washer()
print(wa)      # 显示对象在内存中的地址

wa2 = Washer()
print(wa2)     # 内存地址不一样，说明是不同的对象
```

> 一个类可以实例化出**多个**对象。

### 2.5 实例方法

**定义特征**：由对象调用，至少有一个 `self` 参数。

**关键机制**：执行实例方法时，Python **自动将调用该方法的对象赋值给 `self`**。

```python
class Washer:
    height = 800

    def wash(self):                # self 参数是类中实例方法必须具备的
        print("我会洗衣服")
        print("方法中的self：", self)    # self 表示当前调用该方法的对象

wa = Washer()
print("wa:", wa)
wa.wash()      # wa 与 self 打印出的地址相同
```

> **人话理解**：`self` 就是"我自己"。对象调用方法时，Python 悄悄把对象本身当第一个参数塞进去，所以方法内部能知道"是谁在调用我"。这和 C 语言里手动传指针是一个思路，只是 Python 帮你做了。

### 2.6 实例属性

**格式**：`self.属性名`

```python
class person:
    name = 'bingbing'          # 类属性

    def introduce(self):       # 实例方法
        print("我是实例方法")
        print(f"{person.name}的年龄:{self.age}")    # self.age 是实例属性

pe = person()
pe.age = 18
pe.sex = '女'

pe.introduce()

pe2 = person()
pe2.sex = '男'
print(pe2.sex)
```

**访问权限对比**

| 属性类型 | 能否用对象名访问 | 能否用类名访问 |
| --- | --- | --- |
| 类属性 | 能 | 能 |
| 实例属性 | 能 | **不能，报错** |

> **结论**：实例属性只能由对象名访问，不能由类名访问；而类中的属性是公共的，大家都能访问。
> `pe.sex = '女'` 是给 `pe` 这个对象**单独新增**的实例属性，其他对象依然没有这个属性。

**问题引出**：每实例化一次都需要手动添加一次属性，效率不高 —— 因此引出**构造函数**。

## 三、构造函数与析构函数

### 3.1 `__init__()` 构造函数

**作用**：通常用来做属性初始化或赋值操作。
**注意**：在类实例化对象的时候，会**被自动调用**。

```python
class Test:
    def __init__(self):        # self 是实例方法的标志
        print("这是__init__()函数")

te = Test()    # 只写这一行，就会自动打印函数里的内容
```

**带参数的构造函数（最常用）**

```python
class person:
    def __init__(self, name, age, height):
        self.name = name        # 实例属性，姓名
        self.age = age          # 年龄
        self.height = height    # 身高

    def play(self):
        print(f"{self.name}在打王者荣耀")

    def introduce(self):
        print(f"{self.name}的年龄是{self.age},身高是{self.height}cm")

pe = person('bingbing', 18, 183)
pe.introduce()
pe.play()
```

> **价值**：把"建对象"和"填属性"合成一步。不写构造函数就得 `pe.name = ...`、`pe.age = ...` 一行行手填，容易漏。

### 3.2 `__del__()` 析构函数

**触发时机**：删除对象的时候，解释器会默认调用 `__del__()` 方法。

```python
class person:
    def __init__(self):
        print("我是__init__()")

    def __del__(self):
        print("被销毁了")

p = person()
del p                    # 删除 p 这个对象
print("这是最后一行代码")
```

**执行说明**

- `del p` 语句执行时，内存会立即被回收，会调用对象本身的 `__del__()` 方法。
- 即使不写 `del`，程序执行结束之后，系统也会**自动调用** `__del__()`。
- `__del__()` 主要表示该程序块或函数**已经全部执行结束**。

> **一对搭档**：`__init__` 是"出生时"，`__del__` 是"告别时"。一个是造，一个是拆。

## 四、封装

**定义**：隐藏对象中一些不希望被外部访问到的属性或方法。

### 4.1 隐藏属性（私有权限）

**做法**：在属性名或方法名前加上**两个下划线** `__`。
**效果**：只允许在类的内部使用，无法通过对象直接访问。

```python
class person:
    name = 'James'      # 类属性
    __age = 28          # 隐藏属性

pe = person()
print(pe.name)          # 能正常访问
print(pe.age)           # 访问不了，报错
```

> **底层机制**：所谓"隐藏"，实际上是 Python 把名字**改名**成了 `_类名__属性名`。所以理论上 `pe._person__age` 能取到，但这属于绕过规则，不推荐。
> **人话理解**：像把私房钱藏在床垫夹层——不是真的锁死，但不合规地翻出来就没意义了。

### 4.2 三种命名方式对比

| 写法 | 名称 | 外部可访问 | 子类可继承 | `from xxx import *` 可导入 |
| --- | --- | --- | --- | --- |
| `xxx` | 普通属性/方法 | 任意地方可用 | 是 | 是 |
| `_xxx` | 私有属性/方法（单下划线） | **可以**使用 | **可以**继承 | **不能**导入 |
| `__xxx` | 隐藏属性/方法（双下划线） | **不能**直接访问 | **不会**继承 | **不能**导入 |

> 单下划线开头一般是为了避免与 Python 关键字冲突而采用的命名方法。
> 双下划线这种命名一般是 Python 中的**魔术方法或属性**，都有特殊含义或功能，自己不要轻易定义。

```python
class person:
    name = 'bingbing'
    __age = 53       # 隐藏属性（双下划线）
    _sex = 'male'    # 私有属性（单下划线）

pe = person()
print(pe._sex)              # 使用 对象名._属性名 调用
print(pe._person__age)      # 使用 对象._类名__属性名 访问隐藏属性
```

### 4.3 私有方法与隐藏方法

```python
class Man:
    def __play(self):          # 隐藏方法
        print('玩手机')

    def funa(self):            # 普通方法
        print('平平无奇的实例方法')
        Man.__play(self)       # 在普通实例方法中调用私有方法 —— 不推荐
        self.__play()          # 推荐使用，更简便

ma = Man()
ma.funa()

ma.play()              # 报错，外部无法直接调用
ma._Man__play()        # 绕过写法，不推荐
```

```python
class Girl:
    def _buy(self):            # 私有方法（单下划线）
        print('整天买买买')

girl = Girl()
girl._buy()        # 可以正常调用
```

## 五、继承

**定义**：让类和类之间转变为**父子关系**，子类默认继承父类的属性和方法。

### 5.1 语法

```python
class 类名(父类名):
    代码块
```

### 5.2 单继承

```python
class Person:
    def eat(self):
        print("我会吃饭")

class Gril(Person):      # Person 类的子类
    pass                 # 占位符：类下面不写任何东西时用它占位，不会报错

girl = Gril()
girl.eat()               # 我会吃饭
```

> **结论**：子类可以继承父类的属性，就算子类自己没有，也可以使用父类的。

### 5.3 继承的传递（多重继承关系）

```
A ← B ← C

C（子类）继承于 B（父类）
B（子类）继承于 A（父类）
→ C 类具有 A / B 类的属性和方法
```

> **结论**：子类拥有父类的**父类**的属性和方法。

### 5.4 方法的重写

**含义**：在子类中定义与父类**相同名称**的方法。

#### 5.4.1 覆盖父类方法

```python
class Person:
    def money(self):
        print("一百万需要被继承")

class Man(Person):
    def money(self):
        print("自己赚一千万")     # 覆盖父类的方法

man = Man()
man.money()      # 自己赚一千万
```

#### 5.4.2 对父类方法进行扩展

**两种写法**

| 写法 | 说明 |
| --- | --- |
| `父类名.方法名(self)` | 直接指名道姓调用父类 |
| `super().方法名()` | **推荐使用**，可以调用父类中的其他方法 |

```python
class Person:
    def money(self):
        print("一百万需要被继承")

class Man(Person):
    def money(self):
        # Person.money(self)     # 第一种方法
        super().money()          # 第二种方法
        print("自己赚一千万")

man = Man()
man.money()
# 一百万需要被继承
# 自己赚一千万
```

> **super 是什么**：super 在 Python 里是一个特殊的类，`super()` 是使用 super 类创建出来的对象，可以调用父类中的方法。

## 六、新式类写法

| 写法 | 类型 | 说明 |
| --- | --- | --- |
| `class A:` | 经典类 | 不由任意内置类型派生出的类 |
| `class A()` | — | 语法上不完整，不推荐 |
| `class A(object)` | **新式类** | 继承了 object 类，或该类的子类都是新式类 —— **推荐使用** |

> **派生类**：指子类有不同于父类的属性和方法的时候，就叫派生类。

**object 类**

- `object` 即"对象"，是 Python 为所有对象提供的**基类（顶级父类）**。
- 提供了一些内置的属性和方法，可以使用 `dir()` 查看。

```python
print(dir(object))
```

> **版本差异**：Python 3 以后，如果一个类没有继承任何类，则**默认继承 object 类**，因为 Python 3 以后都是新式类。

## 七、多继承

### 7.1 含义

子类可以拥有**多个父类**，并且具有所有父类的属性和方法。

```python
class 类名(父类名1, 父类名2):
    pass
```

### 7.2 父类存在同名方法

> **开发时应尽量避免这种情况。**

**处理规则：就近原则** —— 括号内哪一个在前面就先调用哪个。

```python
class C(A, B, ...)     # A 在前面，就先调用 A 中重名的方法
```

### 7.3 方法搜索顺序 `__mro__`

Python 中的内置属性 `__mro__` 可以查看方法搜索顺序。

```python
print(类名.__mro__)
```

**查找逻辑**

1. 搜索方法时，先按照 `__mro__` 的输出结果，**从左往右**的顺序查找。
2. 如果在当前类中找到了方法，就直接执行，不再搜索。
3. 如果找到最后一个类还没有找到这个方法，程序就会报错。

### 7.4 多继承的弊端

- 容易引发**冲突**。
- 会导致代码设计的**复杂度增加**。

## 八、多态

**定义**：同一种行为具有**不同的表现形式**。

### 8.1 多态的前提

1. **继承**
2. **重写**

### 8.2 多态性

**一种调用方式，不同的执行结果。**

```python
def test(obj):
    obj.eat()

animal = Animal()     # 父类对象
pig = Pig()           # 子类对象，有 eat 方法
dog = Dog()           # 子类对象，有 eat 方法

test(animal)
test(pig)
test(dog)
```

> **结论**：`test` 函数传入不同的对象，就执行不同对象的 `eat` 方法。
> **人话理解**：同一个"按开关"的动作，按在灯上是亮灯，按在风扇上是转风——指令一样，结果因对象而异。

## 九、静态方法

**标识**：使用 `@staticmethod` 装饰器修饰。
**特征**：**没有 `self`、`cls` 参数限制**。

```python
class Person:
    @staticmethod          # 静态方法
    def study(name):
        print(f"{name}会学习")

Person.study('bingbing')   # 用类访问

pe = Person()
pe.study('bingbing')       # 用对象访问，调用时照常传参数
```

**特点**

- 静态方法与类无关，可以被转换成函数使用。
- 既可以使用**对象**访问，也可以使用**类**访问。
- **目的**：取消不必要的参数传递，有利于减少不必要的内存占用和性能消耗。

> **人话理解**：静态方法就是"挂在类名下面放的一个普通函数"，不需要知道是哪个对象在调用，也不需要知道是哪个类。

## 十、类方法

**标识**：使用装饰器 `@classmethod` 修饰。
**特征**：第一个参数**必须是类对象**，一般以 `cls` 作为第一参数。

```python
class 类名:
    @classmethod
    def 方法名(cls, 形参):
        方法体
```

```python
class Person:
    @classmethod
    def sleep(cls):
        print("cls", cls)      # cls 代表类对象本身，类本质上就是一个对象
        print("人类在睡觉")

print(Person)
Person.sleep()
```

**使用场景**

- 当方法中需要使用到**类对象**（如访问私有类属性等）时，定义类方法。
- 类方法一般是**配合类属性**使用。

## 十一、三种方法对比总结

```python
class Person(object):
    name = "小明"           # 类属性：类所拥有的属性

    def __init__(self):
        self.age = 18       # 实例属性：对象私有的

    def play(self):         # 实例方法
        print(f"{Person.name}在玩游戏")
        print(self.age)

    @staticmethod           # 静态方法：类中的函数，形参没有限制
    def introduce():
        print(f"我是{Person.name}")

    @classmethod            # 类方法：针对类存在的方法
    def introduce2(cls):    # cls 代表类对象本身
        print(cls.name)
```

**对比表**

| 方法类型 | 装饰器 | 第一个参数 | 能否访问类属性 | 能否访问实例属性 | 调用方式 |
| --- | --- | --- | --- | --- | --- |
| 实例方法 | 无 | `self`（对象本身） | 能 | **能** | 对象.方法() |
| 静态方法 | `@staticmethod` | 无限制 | 能（但没意义） | **不能** | 类.方法() / 对象.方法() |
| 类方法 | `@classmethod` | `cls`（类本身） | 能 | **不能** | 类.方法() / 对象.方法() |

> **核心结论**：
> - 类属性是**公共的**，所有方法内部都能访问到。
> - 实例属性是**私有的**，只有**实例方法**内部能够访问到。
> - 静态方法不需要访问类属性，因为静态方法和类、对象都没有关联。
