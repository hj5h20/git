## 一、函数

**含义**：将独立的代码块组织成一个整体，使其具有特殊功能的代码集。
**作用**：提供代码的重用性，使整体代码看上去更加简练。

### 1.1 定义函数

```python
def 函数名():
    函数体
```

### 1.2 调用函数

```python
函数名()
```

> **原则**：调用函数前，**必须保证函数已经存在**。

---

## 二、返回值

函数执行结束后，最后给调用者的一个结果。

### 2.1 return 的作用

```python
def buy():
    return "一桶水果茶"

buy()
print(buy())    # 直接调用函数控制台没有输出结果，得打印出来
```

> **关键区别**：`return` 是**返回**计算结果给调用者，`print` 是**打印**结果到控制台。只写 `buy()` 屏幕上什么也看不到，因为结果只是被"交回来"了，没人接住也没人显示。

### 2.2 return 会终止函数

函数中遇到 `return`，表示此函数**结束**，后续代码不再执行。

### 2.3 注意事项

- `return` 返回**多个值**时，以**元组**的形式返回给调用者。
- 没有返回值时，函数默认返回 `None`。

## 三、参数

### 3.1 形参与实参

```python
# 定义格式
def 函数名(形参a, 形参b):
    函数体        # 如 a=1, b=2

# 调用格式
函数名(实参1, 实参2)
```

> **人话理解**：形参是**定义时留的空位**（食堂窗口贴的"份数"），实参是**调用时真正递进去的东西**（你报的"两份"）。

### 3.2 四种实参形式

#### 3.2.1 必备参数（位置参数）

**含义**：传递和定义参数的**顺序及个数必须一致**。

#### 3.2.2 默认参数

**含义**：为参数提供默认值，调用函数时可不传该默认参数的值。

```python
def func(a=12):      # 正确
def func(a=12, b):   # 错误
```

> **规则**：所有的位置参数必须出现在默认参数**前面**，函数的定义和调用都是如此。
> 设了默认值，没传值就按默认值执行，传了值就按传入的值执行。

#### 3.2.3 可变参数

**含义**：传入值的数量是可以改变的，可以传多个，也可以不传。

```python
def func(*args):
    print(args)      # 以元组的形式接收

func("")
```

> `*` 星号的含义是**可以接收多个值**。`args` 可以改成其他参数名，但 `args` 更符合代码规范。

#### 3.2.4 关键字参数

```python
def func(**kwargs):
    print(kwargs)
    print(type(kwargs))    # 以字典形式接收

func()                            # 空字典
func(name='zhangsan', age=18)     # 传值时采用 键=值 的形式
```

> `**` 双星号接收的是**键值对**，装进字典。作用是**可以扩展函数的功能**。

## 四、函数嵌套

### 4.1 嵌套调用

**含义**：在一个函数里面**调用**另外一个函数。注意是调用，和 if、for 循环的嵌套不一样。

### 4.2 嵌套定义

**含义**：在一个函数中**定义**另外一个函数。

```python
def study():            # 外函数
    print("晚上在学习")

    def course():       # 内函数
        print("python基础")

    course()            # 注意缩进：定义和调用是同级的

study()
```

> **易错点**：`course()` 必须写在 `course` 定义之后、并且缩进与外函数同级。如果写在 `def course()` 内部，就永远调用不到。

## 五、作用域

### 5.1 含义

变量生效的范围，分为**全局变量**和**局部变量**。

### 5.2 全局变量

- 函数**外部**定义的变量，在整个文件中都有效。
- 函数内部如果要使用变量，会**先从函数内部找**，有就直接用；没有再**到函数外面去找**。

### 5.3 局部变量

- 函数**内部**定义的变量，从定义位置开始到函数结束位置有效。
- 只能在被定义的函数中使用，函数外部不能使用。
- **作用**：在函数体内部临时保存数据，函数调用完成后就销毁。

### 5.4 global 关键字

**作用**：将变量声明为全局变量，从而在函数内部修改全局变量的值。

```python
a = 100

def fun2():
    global a       # 声明全局变量
    a = 120
    print(a)

fun2()             # 120
```

> **总结**：`global` 关键字可以对全局变量进行修改，也可以在局部作用域中声明一个全局变量。

## 六、匿名函数 lambda

### 6.1 基本语法

```python
函数名 = lambda 形参: 返回值(表达式)

# 调用
结果 = 函数名(实参)
```

```python
add = lambda a, b: a + b
print(add(1, 2))      # 3
```

### 6.2 lambda 的参数形式

和正常函数所接收的参数一致，此处不赘述。

### 6.3 lambda 结合 if 判断

```python
a = 5
b = 8

# if 语句的三目运算符
print("a比b小") if a < b else print("a大于等于b")

# lambda 结合
comp = lambda a, b: "a比b小" if a < b else "a大于等于b"
print(comp(a, b))
```

> **适用边界**：lambda 只能实现简单的逻辑。如果逻辑复杂且代码量较大，不建议用 lambda，它会降低代码可读性，为后期维护增加困难。

## 七、内置函数

### 7.1 查看所有内置函数

```python
import builtins
print(dir(builtins))
```

### 7.2 常见内置函数

#### 7.2.1 zip()

将可迭代对象作为参数，将对象中对应的元素**打包成一个个元组**。

```python
li = [1, 2, 3]
li2 = ['a', 'b', 'c']

print(zip(li, li2))    # 已经打包成一个东西了

# 取出方式一：for 循环
for i in zip(li, li2):
    print(i)           # 数据类型为元组

# 取出方式二：转换成列表打印
print(list(zip(li, li2)))   # [(1, 'a'), (2, 'b'), (3, 'c')]
```

> **注意**：zip 中的参数必须是**可迭代对象**。如果元素个数不一致，就**按长度最短的**返回。

#### 7.2.2 map()

对可迭代对象中的每一个元素进行映射，分别去执行。

```
map(func, iter1)
# func：自己定义的函数
# iter1：要放进去的可迭代对象
```

```python
li = ['a', 2, 3]

def func(x):
    return x * 8

mp = map(func, li)     # 注意：只用写函数名，不用写括号
print(mp)              # 被打包成一个东西

for i in mp:           # 取出方式一
    print(i, type(i))  # 提出来是什么类型就是什么类型

print(list(mp))        # 取出方式二：转换成列表打印
```

> **关键**：`map(func, li)` 里的 `func` 只写函数名，**不能加括号**——加括号就变成"先把函数执行一遍"，传的是结果而不是函数本身。

#### 7.2.3 reduce()

先把对象中的两个元素取出，计算出一个值保存着，再把这个计算值跟第三个元素进行计算，依次类推。

```python
from functools import reduce      # 需要先导包

li2 = [1, 2, 3, 4]

def add(x, y):
    return x + y

result = reduce(add, li2)
print(result)     # 10
```

```
reduce(function, sequence)
# function：必须是两个参数的函数
# sequence：可迭代对象
```

## 八、拆包

**含义**：对于函数中的多个返回数据，去掉元组、列表或者字典，直接获取里面数据的过程。

### 8.1 方法一：变量个数与元素个数一致

```python
tua = (1, 2, 3, 4)

a, b, c, d = tua
print(a, b, c, d)     # 1 2 3 4

a, b = tua            # 报错：要拆包的值过多
```

> **要求**：元组内的个数与接收的变量个数**必须相同**，对象内有多少个数据就需要定义多少个变量接收。一般用于获取元组值的过程。

### 8.2 方法二：星号接收剩余

```python
a, *b = tua
print(a, b)     # 1 [2, 3, 4]
```

> `*` 号表示接收多个数据，剩下的会打包成列表。一般用于**函数调用时**。

```python
def funa(a, b, *args):
    print(a, b)
    print(args)

funa(1, 2, 3, 4, 5)

arg = (1, 2, 3, 4, 5)
funa(*arg)     # 这里也需要星号，不然会被误以为是一个参数
```

## 九、抛出与捕获异常

### 9.1 抛出异常的两个步骤

1. 创建一个 `Exception('xxx')` 对象，`xxx` 是异常提示信息。
2. 用 `raise` 抛出这个对象。

```python
raise Exception('bingbing抛出了一个异常')
```

```python
def funa():
    raise Exception('冰冰抛出了一个异常')
    print("哈哈")     # 执行了 raise 语法，代码不会继续往下

funa()
```

### 9.2 小案例：密码长度不足就报异常

**需求分析**：用户输入密码，判断长度是否大于等于 6。如果不足 6 位，就抛出自定义异常，并捕获异常。

```python
def login():
    pwd = input("请输入您的密码")
    if len(pwd) >= 6:
        return "密码输入成功"
    raise Exception("长度不足六位，密码输入失败")

print(login())      # 由于 raise Exception 中断，后续代码不会执行
```

改用 `try...except` 捕获：

```python
try:
    print(login())
except Exception as e:
    print(e)
```

> **效果**：这样就能保证异常下面的代码继续正常运行。整个过程称为**捕获异常**，即程序不会终止。
> **对照记忆**：`try` 像"先试一下"，`except` 像 Python 里的 `catch`——出事了走这边，程序不至于直接崩掉。

## 十、模块

### 10.1 含义

**一个 py 文件就是一个模块**。导入一个模块，本质上就是执行一个 py 文件。

### 10.2 分类

| 分类 | 说明 |
| --- | --- |
| 内置模块 | 如 `random`、`time`、`os`、`logging`，直接导入即可使用 |
| 第三方模块（第三方库） | 下载方式：cmd 窗口输入 `pip install 模块名` |
| 自定义模块 | 即自己在项目中定义的模块 |

> **注意**：自定义模块命名要遵循标识符规定以及变量命名规范，**不要与内置模块重名**，否则将导致模块功能无法使用。

### 10.3 导入模块的三种方式

**方式一**：直接 `import 模块`

```python
import 模块名
模块名.功能名        # 调用方式
```

**方式二**：`from ... import ...`

```python
from 模块名 import 指定的功能
```

> 调用时直接写功能名即可，不需要"模块名.功能名"这种形式。

```python
from pytest import funa
funa()      # 导入函数只需要写函数名，不需要小括号
```

**方式三**：`from 模块名 import *`

```python
from 模块名 import *
```

> 其实就是导入模块中**所有**的功能。**不建议过多使用**，有时候命名冲突会造成一些错误。

### 10.4 as 起别名

```python
# 1. 给模块起别名
import 模块名 as 别名

# 2. 给功能起别名
from 模块名 import 功能 as 别名
```

> 导入多个功能时，使用**逗号**与功能隔开，后面的功能也可以取别名。

### 10.5 内置全局变量 `__name__`

**语法**

```python
if __name__ == '__main__':
```

**作用**：用来控制 py 文件在不同的应用场景执行不同的逻辑。

**`__name__` 的两种取值**

| 场景 | `__name__` 的值 |
| --- | --- |
| 文件在当前程序执行（自己执行自己） | `"__main__"` |
| 文件被当作模块被其他文件导入 | 模块名 |

> **注意**：被当作模块导入时，`__name__ == "__main__"` 下面的代码不会被执行。

## 十二、递归函数

### 12.1 含义

如果一个函数在内部不调用其他的函数，而是**调用它本身**，这个函数就是递归函数。

### 12.2 三个必备条件

1. 必须有一个明确的**结束条件** —— 递归出口。
2. 每进行更深一层的递归，**问题规模相比上次都要有所减少**。
3. 相邻两次重复之间有**紧密的联系**。

### 12.3 示例：计算 1~n 的累加和

```python
def add2(n):
    if n == 1:            # 递归出口
        return 1
    return n + add2(n - 1)

print(add2(5))            # 15
```

> **执行过程**：`add2(5)` → `5 + add2(4)` → `5 + 4 + add2(3)` → ... → `5+4+3+2+1`。
> 递归像"剥洋葱"：一层层往里剥，剥到最里面（`n == 1`）再一层层把结果带回来。

## 十三、闭包

### 13.1 三个条件

1. **函数嵌套**（函数里面再定义函数）。
2. **内层函数使用外层函数的局部变量**。
3. **外层函数的返回值是内层函数的函数名**。

```python
def outer():            # 外层函数
    n = 10              # 外层函数的局部变量

    def inner():        # 内层函数
        print(n)        # 内层函数使用外层函数的局部变量

    return inner        # 返回函数名

print(outer())          # 返回的是内部函数的内存地址
```

**两种调用写法**

```python
# 写法一
outer()()

# 写法二
ot = outer()
ot()
```

### 13.2 带参数的闭包

```python
def outer(m):
    n = 10

    def inner():
        print("计算结果：", m + n)

    return inner     # 返回函数名，而不是 inner()

ot = outer(20)
ot()                 # 计算结果： 30
```

> **为什么返回 `inner` 而不是 `inner()`**：返回 `inner` 是"把遥控器交出去"，什么时候按由你决定；返回 `inner()` 是"当场按一下然后交出结果"，就失去了闭包延后执行的能力。

### 13.3 函数引用

```python
def funa():
    print(123)

print(funa)     # 函数名里面保存了函数所在位置的引用
```

- `id()`：判断两个变量是否是同一个值的引用。
- `a = 1` —— `a` 只是一个变量名，存的是 `1` 这个数值所在地址，即 `a` 里存了数值 1 的引用。
- `tes1` 也只是一个函数名，里面存了这个函数所在位置的引用。

### 13.4 闭包变量的关键特性

> **总结**：使用闭包的过程中，一旦外函数被调用一次、返回了内函数的引用，虽然每次调用内函数会开启一个函数、执行后消亡，但是**闭包变量实际上只有一份**，每次开启内函数都在使用同一份闭包变量。

## 十四、装饰器

**作用**：在不改变原有代码的情况下添加新的功能。

**本质**：装饰器本身就是一个**闭包函数**，其返回值也是一个函数对象。

**两个条件**

1. 不修改源程序或函数的代码。
2. 不改变函数或程序的调用方法。

### 14.1 标准版装饰器

```python
# 被装饰的函数
def send():
    print('发送消息')

# 装饰器函数
def outer(fn):            # fn 也是形参，只不过这里专门放函数名
    def inner():          # 既包含原有功能，又包含新功能
        print("登录")
        fn()              # 执行被装饰的函数，即 send()
    return inner

ot = outer(send)
ot()
# 输出：登录
#       发送消息
```

> **原理**：装饰器的原理就是将原有的函数名重新定义为**以原函数为参数的闭包**。

### 14.2 语法糖 `@`

```python
def outer(fn):
    def inner():
        print("登录")
        fn()
    return inner

@outer          # 注意：不要加括号
def send():
    print("发送消息")

send()
```

> `@outer` 这一行和上面 `ot = outer(send)` 是完全等价的写法，只是 Python 提供了更便捷的表示方式。
> **注意**：`@outer` **不要加括号**，加了括号就变成调用函数了。

### 14.3 被装饰的函数有参数

```python
def outer(fn):
    def inner(name):
        print(f"{name}是inner函数中的参数")
        print("哈哈")
        fn(name)
    return inner

@outer
def func(name):
    print("这是被装饰的函数")

func("bingbing")
```

> **易错点**：参数 `name` **一个地方都不能少**——`inner` 的形参、`fn(name)` 的实参，少一处就会报错。

### 14.4 被装饰的函数有可变参数

```python
def outer(fn):
    def inner(*args, **kwargs):
        print("你好")
        fn(*args, **kwargs)
    return inner

@outer
def func(*args, **kwargs):
    print(args)
    print(kwargs)

func()
```

> **通用写法**：装饰器里用 `*args, **kwargs` 通吃所有参数形式，这样装饰器就能套在任何函数上。

### 14.5 多个装饰器

```python
# 第一个装饰器
def decol(fn):
    def inner():
        return "哈哈哈" + fn() + "呵呵呵"
    return inner

# 第二个装饰器
def decol2(fn):
    def inner():
        return "奈斯" + fn() + "非常优秀"
    return inner

# 被装饰的函数
@decol
@decol2
def tes1():
    return "晚上在学习python基础"

print(tes1())
```
